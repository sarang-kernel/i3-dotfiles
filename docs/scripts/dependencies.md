# Dependencies

Generated by scanning every script for the programs it calls. The package column is my mapping to Arch package names (check `pacman -F <program>` if one is wrong on your system). Python programs also need `python-gobject` with **GTK 3** (Spotlight, the power menu, the alarm) and **GTK 4 + libadwaita** (the Settings app).

## Libraries the Python programs load

- `gi` (PyGObject) with Gtk 3.0 and Gdk 3.0 (Spotlight, `power-menu.py`, `alarm.py`), Gtk 4.0 and Adw 1 (`settings.py`), `GdkPixbuf`, `Gio`, `GLib`, `Pango`.
- `ctypes` against `libxcb.so.1` and `libxcb-screensaver.so.0` (the display agent's idle timer) and `libc` (`inotify`).
- Everything else is the standard library (`json`, `sqlite3`, `subprocess`, `tarfile`, `urllib`, `xml.etree` …).
